# AI-Based Smart Energy Monitoring Assistant

This project predicts the next 10-minute household appliance energy consumption from the UCI Appliances Energy Prediction dataset. It is a time-series regression project, so all splits are chronological and no rows are randomly shuffled.

## Current Phase

Phase 1 is implemented and verified for the core ML lifecycle:

- Dataset loading and validation
- Leak-free feature engineering
- Chronological train/validation/test split
- Persistence baseline, Linear Regression, Random Forest, and XGBoost
- MLflow experiment tracking with saved model artifacts
- DVC tracking for `data/raw/energydata_complete.csv`
- PyTest coverage for data, features, splitting, predictions, and metrics

EDA is still pending as a notebook/report artifact.

## Dataset

Raw data:

```text
data/raw/energydata_complete.csv
```

The raw CSV is tracked with DVC:

```text
data/raw/energydata_complete.csv.dvc
```

Do not edit the raw dataset directly.

## Feature Engineering

The pipeline creates:

- Time features: `hour`, `day`, `day_of_week`, `month`, `is_weekend`
- Lag features: `Appliances_lag_1`, `Appliances_lag_2`, `Appliances_lag_3`
- Rolling features: `Appliances_rolling_mean_3`, `Appliances_rolling_mean_6`, `Appliances_rolling_std_6`
- Indoor/outdoor environmental features available at prediction time

Rolling and lag features use past values only.

## Run The Project

From this directory:

```bash
python run_pipeline.py
```

Run tests:

```bash
python -m pytest tests -v
```

Check DVC state:

```bash
python -m dvc status
```

Open MLflow UI:

```bash
mlflow ui
```

If `mlflow` or `dvc` is not on PATH, use:

```bash
python -m mlflow ui
python -m dvc status
```
